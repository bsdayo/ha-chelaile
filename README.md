# 车来了实时公交

Home Assistant 自定义集成，查询指定公交线路、方向和站点的实时到站信息。要求 **Home Assistant 2026.10.4 或更新版本**。

## 安装

- **HACS**：在自定义仓库中添加 `https://github.com/bsdayo/ha-chelaile`，类别选择“集成”，下载后重启 Home Assistant。
- **手动**：将 `custom_components/chelaile` 复制到 Home Assistant 配置目录的 `custom_components` 下，然后重启。

## 配置与使用

在“设置 → 设备与服务 → 添加集成”中搜索“车来了”，依次选择城市、输入线路号、选择方向和站点。单方向线路会自动跳过方向选择。

每个配置提供四个实体：

- **第 1、2、3 辆车到站时间**：分别显示对应车辆预计还有多少分钟到站，属性包含该车的车牌、速度、车辆编号、当前站序、距离、剩余站数、拥挤度和预计到站时刻；接口未提供的字段为空。
- **到站时间汇总**：将前三辆车的剩余分钟数自动拼接为文本，例如 `3m · 8m · 15m`。缺车或到站时间未知的位置显示 `—`，例如 `3m · — · —`；全部未知时显示“未知”。与各车到站时间同步刷新。

车辆按距离由近到远排列，前车离开后后车补位；不足三辆时，空缺实体显示“未知”。只使用实时车辆数据，不根据首末班时刻推算；接口失败时实体显示“不可用”。

默认每 60 秒刷新，可在集成选项中调整为 30–900 秒。手动刷新可调用 Home Assistant 自带的 `homeassistant.update_entity` 动作，目标选择任一车来了实体。

数据由车来了提供，部分城市或线路可能没有实时信息。

## 从旧版升级

2.0 重新设计了配置和实体，不兼容旧版。请删除原有车来了配置，再重新添加，并更新面板和自动化中的实体引用。
